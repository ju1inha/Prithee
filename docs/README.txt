PRITHEE - HOMEWORK 2

Requirements to run program:
* IntelliJ IDEA
* Java 26
* Gradle

How to run:
1. Open IntelliJ IDEA
2. Find the src folder, open main module and then open Main.java
3. Run the Main class
4. Follow the prompts in the console

How to run tests:
1. Find the src folder, open test module and run tests.java
